Evals grade definition wording and agent behaviour against written rules. Code settles what it can; models judge the rest, and a case no tier settles goes to you. See [How it works](/how-it-works#8-evals-grade-what-structure-cannot-show).

- [Evals](https://github.com/SterlingJF/knowledge-bus/blob/main/evals/README.md): the rules and behaviours that define good definitions and agent work, and how they are graded.
- [Evaluation Report](https://github.com/SterlingJF/knowledge-bus/blob/main/evals/report.md): figures from recorded runs.
- [Methodology](https://github.com/SterlingJF/knowledge-bus/blob/main/METHODOLOGY.md): how evals are built, run, and reported.
