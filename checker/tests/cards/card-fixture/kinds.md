# Document types

In the Card fixture universe spec (card-fixture 0.1).

- Visit plan (visit-plan)
  - Also called: site visit plan / risk briefing
  - Helps you: prepare a safe site visit
- Site permit (site-permit)
  - Its shape is set by an outside authority: County site access permit
  - Helps you: enter the site with the owner's permission
- Visit report (visit-report)
  - Helps you: share what the visit found
