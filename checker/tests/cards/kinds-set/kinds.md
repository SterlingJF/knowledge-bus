# Document types

## Factors only universe spec (factors-only 0.1)

No document types.

## Hall bookings universe spec (hall-bookings 0.1)

Covers: The details a village hall records for each booking, from the first enquiry to the return of the keys.

For: The bookings secretary and the people who hire the hall.

- Booking form (booking-form)
  - Helps you: hold the hall for an event
  - Who uses it: hirer
  - When it is used: before the bookings secretary confirms the date

## Hall upkeep universe spec (hall-upkeep 0.1)

Covers: The cleaning, checks and repairs that keep a village hall fit for each hirer.

For: The hall caretaker, the management committee and the people who hire the hall.

- Hirer checklist (hirer-checklist)
  - Helps you: leave the hall ready for the next hirer
  - Who uses it: hirer
  - When it is used: at the end of each event
