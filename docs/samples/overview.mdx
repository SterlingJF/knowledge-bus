Use the reference material as a starting point for your own work. You can adopt it, trim it, extend it, or develop a different set of definitions.

See [Adapting a sample](/adapting-a-sample).

Definitions live in `.knowledge-bus/` inside the folder they describe. Checking from a nested directory uses the nearest `.knowledge-bus/` directory. To use universe specs of the parent folder in a nested folder, list their ids in the nested folder's `.knowledge-bus/workspace.yaml`. See [Knowledge Bus Directory](/knowledge-bus-directory) for discovery and write rules.
